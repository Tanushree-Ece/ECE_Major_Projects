## Digital Design Projects

This directory contains my digital VLSI design and verification projects completed as part of my ECE coursework and self-learning.
The projects focus on RTL design, functional verification, timing analysis, and low-power digital techniques using industry-standard EDA tools.

## Tools and Technologies

-Verilog / SystemVerilog
-Cadence Xcelium / Genus
-GTKWave
-Icarus Verilog
-FSM Design
-Static Timing Analysis (STA)
-Low Power Design Techniques
-UVM-based Verification
