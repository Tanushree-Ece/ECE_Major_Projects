# Simulation Results 
### Single Stage Op-Amp

This folder contains simulation results for the single-stage operational amplifier.

## DC Analysis
- Verified correct biasing
- All transistors operating in saturation/Sub threshold region

## AC Analysis
- Open-loop gain ≈ 40 dB
- Unity gain Bandwidth ≈ 7.07 MHz
- Phase margin ≈ 87 degree

## Transient Analysis
- Stable output swing
- Slew rate verified

### NOTE: For clarity and organization, all simulation waveform plots are stored in the 'Images' folder.
