# Simulation Waveform Images

This folder contains waveform plots and figures generated from simulations of the Single Stage Operational Amplifier.

## Contents
- AC response and gain plots
- Stability and phase margin plots
- Transient response and output swing waveforms
- PSRR and CMRR plots
- Offset Voltage and error plots
- Slew rate plot

## Note
These images are provided as supporting evidence for the simulation results discussed in the 'Simulation' folder README.
