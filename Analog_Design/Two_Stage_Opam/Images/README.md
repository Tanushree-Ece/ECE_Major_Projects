## Simulation Waveform Images

This folder contains waveform plots and figures generated from simulations of the Two-Stage Operational Amplifier.

## Contents

- AC response and overall gain plots
- Frequency response with compensation effects
- Stability analysis and phase margin plots
- Transient response and output swing waveforms
- Slew rate plot
- PSRR and CMRR plots
- Offset voltage and error plots

## Note

These images are provided as supporting evidence for the simulation results discussed in the Two-Stage Operational Amplifier Simulation folder README.
