
## Simulation Results
## Two-Stage Operational Amplifier

This folder contains simulation results for the two-stage operational amplifier.

## DC Analysis

Verified correct biasing for both stages
All transistors operating in saturation region
Proper bias current distribution between first and second stages

## AC Analysis
Open-loop gain ≈ 78 dB
Unity gain bandwidth ≈ 36.685 MHz
Phase margin ≈ 47 degrees (with compensation)

## Transient Analysis

Stable output swing across load conditions
Slew rate verified and improved compared to single-stage design
No sustained ringing or instability observed

For clarity and organization, all simulation waveform plots are stored in the 'Images' folder and are referenced here only for performance verification.
